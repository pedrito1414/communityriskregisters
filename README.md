# CRUK Community Risk Explorer — test website

This is the Climate Resilient UK Community Risk Explorer proof-of-concept, using the preferred v1.0 design.

## Publish with GitHub Pages (no coding needed)

1. Create a **public** GitHub repository called `community-risk-explorer`.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root (not the ZIP file).
3. Go to **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, **Branch** to `main`, and folder to `/(root)`. Save.
5. Visit the URL GitHub displays in Pages settings. It will normally look like `https://YOUR-USERNAME.github.io/community-risk-explorer/`.

## Notes

- This is a public **test prototype**, not a complete, audited collection of UK community risk registers.
- The included registers differ in coverage and scoring approach. Some are narrative-only.
- This is a static, self-contained HTML file; there are no app servers or package dependencies.
- Do not collect household personal data in this version.
- Before public promotion, manually validate scores, source links and accessibility.

## Updating the website

Upload a revised `index.html` to the same repository, replacing the previous file. GitHub Pages will deploy the updated file.
