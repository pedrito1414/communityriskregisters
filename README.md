# CRUK Community Risk Explorer — test website

This is the Climate Resilient UK Community Risk Explorer proof-of-concept, using the preferred v1.0 design.

https://pedrito1414.github.io/communityriskregisters/

## Notes

- This is a public **test prototype**, not a complete, audited collection of UK community risk registers.
- The included registers differ in coverage and scoring approach. Some are narrative-only.
- This is a static, self-contained HTML file; there are no app servers or package dependencies.
- Do not collect household personal data in this version.
- Before public promotion, manually validate scores, source links and accessibility.
